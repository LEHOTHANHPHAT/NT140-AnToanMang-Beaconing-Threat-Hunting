# Cấu hình

B giữ thư mục này. default.json chạy dữ liệu mẫu. Mọi đường dẫn tương đối được hiểu từ gốc repo, không từ thư mục chứa config. input_csv là đầu vào; processed_json và scores_json là output. dataset_id phân biệt nguồn/kịch bản; không chứa ký tự |. baseline.min_events là số sự kiện tối thiểu, số nguyên từ 2 trở lên.

Không có ngưỡng phát hiện mã độc mặc định. Tạo file cấu hình riêng khi thêm dữ liệu thật; không ghi bí mật vào cấu hình commit.
