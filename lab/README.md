# Lab tạo giao tiếp

A triển khai ở tuần 5: HTTP client/server đơn giản trên máy hoặc mạng lab của nhóm, tạo nhịp đều, dao động và dịch vụ hợp lệ định kỳ. Không cần mã độc thật để kiểm tra pipeline thời gian. Chưa có code lab chạy trong bộ khung.

Code client đặt trong client/, server trong server/. Log thu được lưu trong data/raw/ kèm mô tả. Thời điểm và nhãn mô phỏng không dùng thay bằng chứng tấn công thật.
